# /dev:plan — write an implementation plan

Pause the current work and follow [[dev/plan/guide]] to write one right-sized implementation plan for: $ARGUMENTS

For an effort that splits into independent planning slices along domain seams, follow [[dev/plan/roadmap]]. Do not implement as part of this invocation.
